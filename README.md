# Intro to NLP

This repository contains my learning journey in **Natural Language Processing (NLP)** using Python and Jupyter Notebook.
The notebooks demonstrate fundamental text preprocessing techniques and practical NLP concepts.

## Topics Covered

1. **Lowercasing**

   * Converting text into lowercase for normalization.

2. **Stopwords Removal**

   * Removing common words that do not add significant meaning.

3. **Regular Expressions**

   * Cleaning and extracting patterns from text.

4. **Tokenization**

   * Splitting text into words or sentences.

5. **Stemming**

   * Reducing words to their root form.

6. **Lemmatization**

   * Converting words into their dictionary base form.

7. **N-grams**

   * Generating word combinations for language modeling.

8. **Practical NLP Example**

   * Applying preprocessing techniques on a real dataset.

## Dataset

The project uses the **TripAdvisor Hotel Reviews dataset**, which contains customer reviews used for practicing text preprocessing.

File included:

* `tripadvisor_hotel_reviews.xlsx`
