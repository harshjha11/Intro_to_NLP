# Intro to NLP

This repository documents my learning journey in **Natural Language Processing (NLP)** using **Python and Jupyter Notebook**.  
The notebooks demonstrate fundamental **text preprocessing techniques and core NLP concepts** implemented using practical examples and datasets.

---

## Topics Covered

### 1. Text Preprocessing

**Lowercasing**

- Converting text into lowercase to normalize words and reduce vocabulary size.

**Stopwords Removal**

- Removing commonly used words (e.g., *the, is, and*) that add little semantic meaning.

**Regular Expressions**

- Using pattern matching to clean and extract useful text patterns.

**Tokenization**

- Breaking text into smaller components such as **words or sentences**.

**Stemming**

- Reducing words to their root form by removing suffixes.

**Lemmatization**

- Converting words into their dictionary base form while preserving meaning.

**N-grams**

- Generating combinations of words to understand context in language models.

---

### 2. NLP Techniques

**Part-of-Speech (POS) Tagging**

- Identifying grammatical roles of words in a sentence such as **noun, verb, adjective, etc.**

**Named Entity Recognition (NER)**

- Detecting and classifying entities in text such as:
  - Person
  - Organization
  - Location
  - Date

---

### 3. Practical NLP Implementation

Practical notebooks demonstrate how to combine multiple NLP techniques such as:

- Tokenization
- POS Tagging
- Named Entity Recognition

to analyze real-world text data.
